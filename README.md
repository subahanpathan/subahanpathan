## Engineering Principles

**01 — Automate repetitive work**  
If a process can be made repeatable, predictable, and less manual, automate it.

**02 — Build for production**  
Development is only one part of engineering. Deployment, reliability, security, and observability matter too.

**03 — Prefer maintainable systems**  
Choose clear architecture and understandable code over unnecessary complexity.

**04 — Secure by default**  
Treat secrets, permissions, dependencies, and production environments as first-class engineering concerns.

**05 — Ship continuously**  
Use version control, CI/CD, testing, and incremental delivery to reduce deployment risk.
